# Critic 影子评分：两次采样，都是 0 违规

目的：在把“分析 → 反驳 → 拒答/补数”接进图之前，先量一下**门控会开火几次**。
critic 的检查是确定性的（数字接地 + 空章节），但分析文本是 LLM 生成的，
所以抽了两次样：

| 样本 | 来源 | 有效标的 | 有违规 | 未接地数字 | 带数字条目 |
|---|---|---:|---:|---:|---:|
| 离线重打分 | 复用 `eval/results/20261102_news20/` 已保存的分析文本 | 20 | **0/20** | 0 | 90.2% |
| 在线新生成 | `CRITIC_ENABLED=1` 跑同一磁带，重新采样分析/报告 | 20 | **0/20** | 0 | 93.3% |

4 个无效代码（ZZZZZZ / INVALID / NOTAREAL / 12345）都走了拒答路径，
critic 没有误报“空章节”——因为没有财务数据时，空分析是预期行为。

## 结论

**按“未接地数字”做门控，在这套数据上一次都不会触发。** 加一个拦截节点、
一条重试/拒答路由，换不来任何可测收益；critic 保留为可选诊断节点
（`CRITIC_ENABLED=1`），不做路由。

这不是“critic 写得对”，而是数据说明**当前输出来没有可拦的东西**：
90%+ 的条目带数字，数字全部能回溯到财务字段或新闻正文。真正没被覆盖的是
语义口径（季度 EPS `$2.02` 与年度 EPS `8.74` 都是真数，并排出现仍会误导），
字面接地检查按设计看不见这种问题。

## 局限

- 两次采样共用同一份新闻磁带（新闻固定），只重采样了分析/报告。
- 单日、n=24（有效 20）；0/20 不等于永远为 0，只能说“在这批输入上不开火”。
- 接地是字面匹配：派生值（P/E = 价格/EPS、增长率）会被判未接地，
  但这两次采样里分析文本没有出现这种派生值，所以没暴露该边界。
- 在线那次是 2026-11-03 跑的历史新闻（磁带录于 11-02），不是实时新闻。

