# ADR-0002：InvestIQ 自主性与记忆升级的范围与顺序

- 状态：提议（2026-11-02），待拍板
- 取代：一份 630 行的远端盲写升级计划（未入库）
- 依据：本机核对 + [`docs/experiments/2026-11-02-coverage/`](../experiments/2026-11-02-coverage/report.md)（只读 `eval/cassettes/frozen.json`，不联网、不调 LLM）

## 1. 背景

现网是固定 DAG：4 节点、67 个离线测试全绿、冻结输入回放、700 个数字 0 未接地。原计划要在 10–14 个工作日内加“有界 ReAct + 分层记忆 + 2×2 评测”，并据此改写简历。

本机核对发现三处硬伤：基线落后一个未合并的 resilience 提交（现已 FF 合入 `b1e91b8`）；计划里的新检索函数会绕过冻结层的补丁点；checkpointer 与 `Annotated[list, add]` 组合会让同一 thread 的 `news_findings` 跨轮累加（已用 15 行复现）。

## 2. 实验结论（决定本 ADR 的四组数）

| 观察 | 数字 | 含义 |
|---|---|---|
| 来源构成 | 120 条里 76 条（63.3%）是聚合/导航页，媒体仅 14 条（11.7%），视频社交 7 条 | 再加查询，大概率还是同一类页面 |
| 槽位覆盖（严格口径，20 只有效标的） | 平均 **2.00/5**；5 槽全满 0/20；财报 19/20、分析师 9/20，但**风险/法律 2/20、重大事件 3/20** | “单次搜索覆盖不足”**成立**，缺口在风险与事件 |
| 故事去重 | 15/24 个 ticker 的 5 条是 5 个不同故事，其余 ≤4 | 重复不算严重，问题不是“条数不够” |
| 回放天花板 | 每 ticker 恒 5 条，fixed 已消费 5/5，`search_company_news` 与 query 无关 | replay 下**新增证据恒为 0**；2×2 必须先改造评测层 |

补充试点（2026-11-02，5 标的、真实 Tavily、严格口径）：基线 5 条 **2.00/5** → 同一条查询取 20 条 **4.00/5** → 4 条查询约 20 条 **4.40/5**。**取数条数是主要杠杆，查询多样性只值约 0.4 个槽位**，成本却是 4 倍搜索。详见 [`docs/experiments/2026-11-02-slot-queries/`](../experiments/2026-11-02-slot-queries/README.md)。

报告层验证（2026-11-02，两臂各 24 标的）：5 条 → 20 条，严格槽位 **2.45 → 3.60**、未接地数字 **3 → 0**、平均单次成本 **1.77×**、p95 **1.23×**、prompt tokens **2.38×**。按预注册规则（未接地不回退且成本 ≤2×）默认改 20；证据与复跑命令见 [`docs/experiments/2026-11-02-max-results/`](../experiments/2026-11-02-max-results/README.md)。

Critic 影子评分做了两次独立采样：离线重打分（复用 20 条臂分析文本）0/20 违规、0 未接地、90.2% 条目带数字；在线重跑（`CRITIC_ENABLED=1`，同一磁带重新采样）仍是 0/20、0 未接地、93.3%。字面接地检查在当前输出上没有可拦的东西——这是 S4 不做门控的直接依据。

结论一句话：**缺口是真的，但瓶颈在取数条数与来源，不在查询规划。** 先调 `max_results`、再换来源（IR/SEC、司法与通讯社），最后才谈循环；且不改造评测层，任何收益都无法被公平测量。

## 3. 决策

1. **不按原 7 阶段计划执行。** 保留其红线（不给 financial 加 LLM、无界循环、LLM 自由文本入记忆、改评测集）、配置默认值、决策规则与回滚策略；删除其“现状/字段表/提示词”章节——已被本机事实改写或会被实现改写。
2. **先收尾**：`feat/resilience-timeouts` 已 FF 合入 `main`（`b1e91b8`），新工作从 `main` 开分支。
3. **顺序改为**：
   - S1 契约测试入库（`tests/test_contract.py`；全套 **80 passed / 4 skipped**）
   - S2 checkpointer + `thread_id`，**同时解决跨轮累加**（run 级隔离或显式清空），默认关闭
   - S3 取数扩容（**已完成 2026-11-02**）：`max_results` 默认 20，可用 `TAVILY_MAX_RESULTS=5` 回退；若仍有缺口，再加一条确定性定向查询。多查询与 ReAct 都不在这一步
   - S4 运行时 critic（**影子已实现 2026-11-02**）：接地检查已抽到 `tools/grounding.py`，eval 与运行时共用；两次采样均 **0/20 违规、0 个未接地数字**，所以不做拦截路由，`CRITIC_ENABLED` 默认 0，只作为可选诊断节点
   - S5 只有 S3 扩容与定向查询都补不上缺口，才评估 LLM 规划循环（ReAct）
4. **评测层先改造再谈 A/B**：把 `frozen.json` 变成“离线语料 + 确定性检索器”，两臂同池、**等搜索预算**；cassette 只做回归。槽位指标改用严格口径（关键词在标题，或与公司名同句），宽松口径只作对照——导航栏会把 `SEC Filings` 当成风险证据。
5. **简历口径后置**：先跑数再写词。若对照无提升，就写“验证了有界自主在本数据上不划算，默认保持 fixed”——这也是一份可讲的工程结论，但不许先写“自判充分性”。

## 4. 不做（红线）

不给 financial 加 LLM；不做无界循环；不让 LLM 自由文本写长期记忆；不改评测集/断言/阈值；开关关闭时行为与今天等价；不为通过评测改默认值。

## 5. 验收与决策规则

- 每个切片 = 一个 PR + 一条可复制命令 + 测试；默认关闭时旧测试与 10 条契约测试全绿，回放结构不变。
- ReAct 保留条件：等预算、同池、幻觉不回退、**风险/事件槽位覆盖每标的 +1**；否则默认 fixed 并写负结果。
- 记忆默认开条件：warm run 成本或延迟降 ≥20%、stale=0、质量不降；否则默认 off。

## 6. 风险（本机已证实的三条）

| 风险 | 证据 | 对策 |
|---|---|---|
| checkpointer 跨轮累加 | `['run'] → ['run','run']` | S2 必须写隔离测试，不接受只测 `get_state` |
| 检索函数改名即破回放 | `fixtures.TARGETS` 按名字打补丁 | 契约测试 `test_eval_fixture_targets_still_exist` |
| 槽位“补满”诱导编造 | 风险/法律本就常无新闻 | 空槽如实报空；停止条件用“无新信息 + 预算”，不用“槽位满” |
| 指标把导航栏当证据 | 宽松口径下 `SEC Filings` 命中“风险/法律” | 严格口径 + 误判样例留档（见试点报告） |

2. ~~是否接受“负结果”作为交付物~~ → **已接受（2026-11-02）**：负结果保持默认并如实记录；S5 保留但延后。
